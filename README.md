Nombre del proyecto: Alrededor de los Estados Unidos

Descripción del proyecto:
Este proyecto ofrece a los usuarios un espacio virtual para compartir sus experiencias de exploración y descubrimiento en distintos lugares de los Estados Unidos. Cada usuario puede crear su propio perfil, publicar fotografías de los sitios que ha visitado y descubrir las aportaciones de otras personas con intereses similares. El objetivo es crear una comunidad donde las imágenes y relatos de viaje inspiren a otros a explorar nuevos destinos.

El desarrollo de este proyecto tuvo como propósito principal aplicar y reforzar conocimientos en JavaScript, particularmente en el manejo y manipulación de arrays, así como en la creación de funciones para gestionar de forma dinámica la información del sitio.
